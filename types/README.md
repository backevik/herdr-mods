# types

`gpui-kit.d.ts` is a copy of the type declarations the [Herdr app](https://herdr.dev) writes into every mod folder it loads: `gpui-kit`, `gpui-base`, `herdr`, `fs/promises` and the other built-in modules. CI type-checks the mods against it, since a CI runner has no Herdr app. `VERSION` is the app it came from.

Don't edit it. After updating Herdr, open the app and run `scripts/update-types.sh`; `./check.sh` warns when it is out of date. It is generated by Herdr, which is [Apache 2.0](https://github.com/herdrdev/herdr/blob/main/LICENSE).
